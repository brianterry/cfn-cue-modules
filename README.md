# cfn-cue-modules

CUE module definitions for authoring AWS CloudFormation templates with full type safety and compliance validation.

Generated by [cfn-cue-gen](../cfn-cue-gen/) from:
- [CloudFormation Resource Provider Schemas](https://docs.aws.amazon.com/cloudformation-cli/latest/userguide/resource-type-schema.html) (1,651 resource types)
- [aws-guard-rules-registry](https://github.com/aws-cloudformation/aws-guard-rules-registry) (112 rules across 50 compliance frameworks)

## Structure

```
cfn-cue-modules/
├── cfn/                      # Base template types (#Stack, #ResourceBase, #Tag, etc.)
├── fn/                       # Intrinsic functions (#Ref, #GetAtt, #Sub, etc.)
└── resources/                # Generated resource modules (1,651 resource types)
    └── aws.cloudformation.dev/

        │       └── ... (50 frameworks)
        ├── ec2/instance/
        ├── lambda/function/
        ├── iam/role/
        └── ... (1,651 total)
```

## Usage

To use these modules in a CUE project, vendor them into `cue.mod/gen/`:

```bash
# Copy the base modules
cp -r cfn-cue-modules/cfn your-project/cue.mod/gen/aws.cloudformation.dev/cfn
cp -r cfn-cue-modules/fn your-project/cue.mod/gen/aws.cloudformation.dev/fn

# Copy specific resource modules you need
cp -r cfn-cue-modules/resources/aws.cloudformation.dev/s3/bucket \
      your-project/cue.mod/gen/aws.cloudformation.dev/s3/bucket
cp -r cfn-cue-modules/resources/aws.cloudformation.dev/ec2/instance \
      your-project/cue.mod/gen/aws.cloudformation.dev/ec2/instance
```

Then import them in your CUE files:

```cue
package infra

import (
    "aws.cloudformation.dev/cfn"
    "aws.cloudformation.dev/fn"
    "aws.cloudformation.dev/s3/bucket"
    "aws.cloudformation.dev/s3/bucket/compliance"
)

stack: cfn.#Stack & {
    Resources: MyBucket: bucket.#Resource & compliance.#NIST800_53Rev5 & {
        Properties: {
            BucketName: "my-bucket"
            BucketEncryption: ServerSideEncryptionConfiguration: [{
                ServerSideEncryptionByDefault: SSEAlgorithm: "aws:kms"
            }]
        }
    }
}
```

## Regenerating

```bash
# Download latest schemas
curl -sL "https://schema.cloudformation.us-east-1.amazonaws.com/CloudformationSchema.zip" -o schemas.zip
unzip -o schemas.zip -d schemas/

# Clone guard rules
git clone --depth 1 https://github.com/aws-cloudformation/aws-guard-rules-registry.git

# Regenerate
cfn-cue-gen schema --input ./schemas --output ./resources
cfn-cue-gen guard \
    --input ./aws-guard-rules-registry/rules \
    --mappings ./aws-guard-rules-registry/mappings \
    --output ./resources
```
